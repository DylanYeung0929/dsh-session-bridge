## 二、正文（直接复制，含标签）

```text
用 DeepSeek Harness 的应该都有这个痛点：每个对话都是独立 agent，各聊各的，互相看不见。

想让 A 知道 B 跑到哪了？只能手动切窗口、复制、粘贴。我受不了了，写了个插件 dsh-session-bridge，现在已经开源 👇

它做三件事：
📋 列出所有会话：标题、目录、是不是正在跑、token 用量
📖 直接读任意会话最近 N 条消息——App 没开也能读
✉️ 往任意会话追加一句话，让那个会话自己的 agent 真的跑一轮

还有个 chat 模式：每轮回完只打印一行菜单「1继续 2切换 3上下文 4退出」，手机上盲打也能用。

三个我已经在用的场景：
1️⃣ 在 B 会话里说「去问问那个会话进度」，agent 自己 read/send 到 A，再把结果带回来
2️⃣ 拿一个会话当调度器，给几个会话分别派活，等回复、做汇总
3️⃣ 晚上躺床上，用脚本/IM 继续白天电脑上没跑完的那个对话

实现不复杂：复用桌面 App 自己的本地 JSON-RPC（从 Cookie 里的 JWT 拿端口），读消息直接 zstd 解磁盘上的转录。纯 Python 标准库 + Node，零第三方依赖，也能直接当 CLI 用：

dshctl list
dshctl tail "安装插件" 10
dshctl prompt "安装插件" "汇报进度" --wait 90

两个我特意较真的地方：
· 会话名有歧义时直接报错并列出候选，绝不悄悄选第一个（读错会话比报错可怕）
· API Key 只走内存，状态文件里不出现

说点实话：
⚠️ 目前只支持 macOS
⚠️ 「发消息」要求 App 在跑；读转录不需要
⚠️ 发出去的内容目标 agent 会当成你说的话，别拿它代做危险操作
✅ 13 个离线单测 + 1 个插件契约测试，GitHub Actions 已跑绿，MIT 开源

仓库 GitHub 搜 dsh-session-bridge（作者 DylanYeung0929）。
觉得有用给个 ⭐；想要 Linux 支持评论区喊一声，人多我就做。

#DeepSeek #DeepSeekHarness #AI工具 #开源项目 #效率工具 #程序员日常 #独立开发 #AIAgent #自动化 #Mac软件
```
